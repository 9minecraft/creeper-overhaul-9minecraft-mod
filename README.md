# Creeper Overhaul — Find Unique Biome Creepers

Creeper Overhaul 9minecraft Mod fills your world with completely new types of creepers based on where you travel. Instead of seeing the same green monster everywhere, you will find special creepers that match their home biomes. This mod changes how they look, how they move, and even how they act around players. Some creepers are still dangerous and will blow up, but others are actually friendly and safe to be around.

## What this build is

An unofficial rebuild of **ThatGravyBoat**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
